# Gates de aprendizagem

Um módulo está concluído quando a pessoa consegue produzir a evidência e explicar a decisão
sem copiar o laboratório. Use 80% como piso para os itens objetivos e refaça o que falhar.

| Gate | Pergunta de passagem | Evidência mínima |
|---|---|---|
| Fase 0 | Consigo ler, alterar e testar um programa pequeno? | classificador por regras, testes e README |
| Módulos 1–2 | Consigo explicar o caminho token → logits e localizar um bug de máscara? | previsão escrita, execução e teste que falha antes da correção |
| Módulos 3–4 | Consigo relacionar uma curva a uma decisão e auditar os dados? | curva comentada + manifesto sem vazamento/PII pendente |
| Módulos 5–6 | Consigo justificar treino e adapter contra uma baseline? | comando reproduzível, métricas e memória antes/depois |
| Módulo 11 | Consigo escolher um ponto de operação? | tabela de qualidade, latência, memória e custo |
| Módulos 13–15 | Consigo fazer o sistema recusar ou pedir ajuda? | citação/abstenção, ferramenta validada e limite de passos |
| Módulo 19 | Consigo operar sem esconder falhas? | p50/p95, logs sem PII, guardião, disjuntor e rollback |
| Projeto | Outra pessoa consegue verificar minha conclusão? | repositório limpo, baseline, dados, avaliação e limitações |

## Checklist do estudante

Antes de avançar, copie este bloco para [`PROGRESSO.md`](PROGRESSO.md) e marque a data:

```text
- [ ] Previ o resultado antes de executar o laboratório.
- [ ] Executei o caminho principal em ambiente limpo.
- [ ] Resolvi os exercícios sem abrir o gabarito.
- [ ] Registrei um erro ou uma surpresa no diário.
- [ ] Produzi a evidência do gate.
- [ ] Expliquei o resultado em até cinco minutos.
```

O gate mede competência demonstrada, não quantidade de páginas lidas.
