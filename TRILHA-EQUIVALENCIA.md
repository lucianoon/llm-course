# Trilha de equivalência

Use este mapa para entrar no curso sem repetir conteúdo que você já domina. Faça o diagnóstico
curto, execute o gate indicado e só então pule para a próxima etapa.

## Diagnóstico rápido

| Se você já concluiu... | Entrada recomendada | Gate antes de avançar |
|---|---|---|
| Python, Git e testes | Módulo 1 | executar o laboratório inicial e `pytest` |
| fast.ai ou deep learning introdutório | Módulo 2 | implementar atenção causal e explicar cada tensor |
| Hugging Face LLM Course até o capítulo 4 | Módulo 4 | comparar tokenização, fine-tuning e baseline |
| Hugging Face LLM Course completo | Módulo 11 ou 13 | avaliar um sistema com conjunto de teste separado |
| Full Stack LLM Bootcamp | Módulo 14 | registrar métricas, intervalo de confiança e falhas |
| Stanford CS336 | Módulo 11 ou 17 | benchmark de inferência e relatório de custo |
| experiência profissional com APIs de LLM | Módulo 2 | reconstruir o pipeline sem depender de API externa |

## Regras de aproveitamento

1. Um certificado ou vídeo não substitui o gate prático.
2. Se o gate falhar, volte somente ao módulo que cobre a lacuna.
3. A trilha essencial continua sendo a rota recomendada para quem não sabe onde entrar.
4. Registre no relatório final quais módulos foram pulados e qual evidência justifica o salto.

## Rotas de aprofundamento

- **Pesquisa e treino:** módulos 1–4 → 16–18 → [Fase 3](FASE-3-MAESTRIA.md).
- **Aplicações e produção:** módulos 1–6 → 11 → 13–15 → 19.
- **Ecossistema Hugging Face:** módulos 1–2 → 5–6 → 11 → 13–15.
- **Sistemas:** módulos 2–4 → 11 → 17 → benchmark final do módulo 19.
